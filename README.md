# Delicious Bites

A responsive restaurant website built with HTML, CSS, and JavaScript. It showcases the restaurant's menu, gallery, and contact details across multiple pages with a shared navigation and footer.

## Pages

- **index.html** — Home page with a hero section, today's deals, and a global footer
- **menu.html** — Food menu with cards showing prices in PKR
- **gallery.html** — Image gallery with filters for categories like drinks, desserts, and pasta
- **about.html** — Information about the restaurant
- **contact.html** — Contact form and contact details

## Features

- Fully responsive layout that adapts to mobile, tablet, and desktop screens
- Mobile navigation menu toggle
- Image carousel/slider on the home page
- Modal popups for viewing menu item details
- Gallery filtering by category
- Active page highlighting in the navigation bar

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/Azam-1071/delicious-bites.git
   ```
2. Open `index.html` in your browser, or use a live server extension in your code editor.

## Branches

- `main` — final, merged version of the project
- `feature/menu-update` — menu cards with PKR pricing and new items
- `feature/gallery-filters` — gallery filters for drinks, desserts, and pasta
- `feature/contact-about` — contact form and about page content
- `feature/responsive-style` — responsive layout styling and JS handlers
